# Luck Swan Sales — ระบบฝ่ายขาย ลักษวรรณ รีสอร์ต

เว็บแอป (PWA) สำหรับฝ่ายขาย ใช้ได้บนโทรศัพท์ แท็บเล็ต iPad และคอมพิวเตอร์ ติดตั้งลงหน้าจอโฮมได้ และใช้งานออฟไลน์ได้หลังเปิดครั้งแรก

## หน้าจอ

| ใบเสนอราคาใหม่ | วิซาร์ด 5 ขั้น (ลูกค้า → ห้องประชุม → อาหาร → ห้องพัก → สรุป) พร้อมพรีวิวยอดสด |
| ตัวอย่างและส่ง | เอกสารใบเสนอราคาเต็มรูปแบบ + ยอดเป็นตัวอักษรไทย, ส่งทางอีเมล / LINE / ลิงก์ / พิมพ์-PDF |

## เริ่มใช้งาน
- เปิดผ่านเว็บเซิร์ฟเวอร์ใดก็ได้ (เช่น GitHub Pages) ที่โฟลเดอร์ `sales-app/` — ต้องเป็น `https://` เพื่อให้ติดตั้งเป็นแอปและใช้ออฟไลน์ได้
- ทดสอบในเครื่อง: `cd sales-app && python3 -m http.server 8080` แล้วเปิด http://localhost:8080
- บัญชีตัวอย่าง: `napassorn@luckswangroup.com` (พนักงานขาย), `laksika@luckswangroup.com` (ผู้ดูแลระบบ) — รหัสผ่านเริ่มต้น `luckswan` (ควรเปลี่ยนทันทีจากเมนูรูปโปรไฟล์)

## นำเข้ากำหนดการใบฟังก์ชันจากไฟล์
1. เปิดหน้า **ใบฟังก์ชัน** → เลือกงาน → ในกล่อง “กำหนดการ” กด **นำเข้าจากไฟล์**
2. กด **ดาวน์โหลดแม่แบบ Excel** (หรือ CSV) — ไฟล์มีกำหนดการปัจจุบันของงานนั้นเป็นตัวอย่าง
3. กรอก 1 แถวต่อ 1 รายการ: `วัน | เวลา | รายละเอียดงาน | สถานที่ | แผนก` แล้วบันทึก
   - วัน: 1, 2, … หรือวันที่จริง (12/11/2569, 2026-11-12, 12 พ.ย. 2569) · เว้นว่าง = วันที่เปิดอยู่
   - เวลา: 06:00, 6.00, 0600 หรือช่วง 10:00–10:30 (ใช้เวลาเริ่ม)
   - แผนก: ครัว, จัดเลี้ยง, ช่าง/AV, ส่วนหน้า, แม่บ้าน, บัญชี (ไทย/อังกฤษได้)
4. กด **เลือกไฟล์** → ตรวจตัวอย่าง (แถวสีแดงจะไม่ถูกนำเข้า พร้อมบอกสาเหตุ) → เลือก *เพิ่มต่อ* หรือ *แทนที่ทั้งหมด* → **นำเข้า**

รองรับ .xlsx และ .csv (Excel / Google Sheets / LibreOffice) — ไม่รองรับ .xls รุ่นเก่า, Word และ PDF

## ฐานข้อมูลกลาง (Cloudflare) และระบบอนุมัติ
เมื่อเปิดแอปจากที่อยู่ของ Cloudflare Worker แอปจะใช้ฐานข้อมูลกลางอัตโนมัติ (ทุกเครื่องเห็นข้อมูลเดียวกัน ล็อกอินตรวจที่เซิร์ฟเวอร์ และใบฟังก์ชันที่แก้โดยตำแหน่งต่ำกว่าต้องได้รับอนุมัติก่อนส่ง) — วิธีติดตั้งดู `worker/DEPLOY.md`
ถ้าเปิดจาก GitHub Pages หรือไฟล์ในเครื่อง แอปจะทำงานแบบเก็บข้อมูลในเครื่องเหมือนเดิม

## ข้อมูล
- ข้อมูลเก็บใน `localStorage` ของแต่ละเครื่อง/เบราว์เซอร์ — ยังไม่แชร์ระหว่างเครื่อง
- ย้าย/สำรองข้อมูล: เมนูรูปโปรไฟล์ → “สำรองข้อมูล” / “นำเข้าข้อมูลสำรอง” (ไฟล์ JSON)
- ระบบล็อกอินเป็นการป้องกันระดับหน้าเว็บเท่านั้น หากต้องการใช้ข้อมูลร่วมกันหลายคนอย่างปลอดภัย ควรเชื่อมฐานข้อมูลกลาง (เช่น Google Sheets + Apps Script หรือ Firebase)
- แก้ราคา/ห้อง/เมนู: `js/data.js` (MEETING_ROOMS, ROOM_TYPES, FOOD, SERVICES) — หลังแก้ไฟล์ ให้เปลี่ยน `CACHE` ใน `sw.js` เป็นเวอร์ชันใหม่ เพื่อให้เครื่องที่ติดตั้งแล้วโหลดของใหม่
